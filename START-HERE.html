Your website.
Ready for its next address.

A manual GitHub upload guide. Just Chrome and File Explorer.

No terminal, VS Code, Copilot, development tools, or Codex–GitHub connection is required. GitHub builds and publishes the website for you.

01 / EXTRACT

Unpack the project.

Save elite-estates-complete.zip to your computer. In Windows File Explorer, right-click it, choose Extract All…, then Extract.

Open the extracted folder. You should see index.html, package.json, src, public, and .github together. If needed, use View → Show → Hidden items.

02 / CREATE YOUR REPOSITORY

Give the project its home.

In Chrome, sign into GitHub and create a new repository.

  • Repository name: elite-estates — use this exact spelling.
  • Visibility: Public, to use GitHub Pages with GitHub Free.
  • Select Add a README file, then create the repository.

03 / ENABLE PAGES

Let GitHub handle the build.

In your repository, choose Settings → Pages. Under Build and deployment → Source, select GitHub Actions.

The project already includes its deployment workflow. You do not need to configure another template.

04 / UPLOAD

Upload the contents, including folders.

  1. Return to your repository’s Code tab.
  2. Choose Add file → Upload files.
  3. In File Explorer, open the extracted project folder and select all its contents. Drag those files and folders into Chrome’s upload area.
  4. Wait until every file finishes uploading.
  5. Enter “Add complete ÉLITE ESTATES website” as the commit message and choose Commit changes to main. If GitHub requires a new branch, create and merge the pull request in the browser.
Check the repository root: package.json must be directly visible. Do not upload the ZIP or an enclosing project folder. Confirm .github/workflows/deploy.yml is present.
If the .github folder was not uploaded

Choose Add file → Create new file. Enter .github/workflows/deploy.yml as the filename. Copy the entire workflow below into GitHub’s editor, then commit to main. The workflow is also inside your extracted project and can be opened in Notepad.

name: Deploy ÉLITE ESTATES to GitHub Pages

on:
  push:
    branches: [main, master]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: pages
  cancel-in-progress: false

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - name: Check out source
        uses: actions/checkout@v6
      - name: Set up Node
        uses: actions/setup-node@v4
        with:
          node-version: '22'
          cache: npm
      - name: Install locked dependencies
        run: npm ci
      - name: Build production website
        run: npm run build
      - name: Configure Pages
        uses: actions/configure-pages@v5
      - name: Upload production website
        uses: actions/upload-pages-artifact@v4
        with:
          path: dist
  deploy:
    needs: build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - name: Deploy website
        id: deployment
        uses: actions/deploy-pages@v4

05 / WATCH THE DEPLOYMENT

Wait for two green checks.

Open the repository’s Actions tab. Select Deploy ÉLITE ESTATES to GitHub Pages. Both build and deploy must finish successfully.

If no run starts, select the workflow, choose Run workflow, select main, and click Run workflow. If an earlier run failed because Pages was not yet enabled, enable it and run the workflow again.

06 / VISIT YOUR SITE

Your live address.

Open Settings → Pages → Visit site, or click the deployment URL in the successful Actions run.

https://USERNAME.github.io/elite-estates/

Replace USERNAME with your actual GitHub username. Detail links include a hash, for example /elite-estates/#/properties/azure-villa. This is intentional and supports reliable reloads on GitHub Pages.

A few useful details.

  • Opening index.html locally: the React source requires a build. Use the live GitHub Pages URL; this guide is the file you can open directly in Chrome.
  • Contact form: a clearly labeled portfolio demo. It creates a local draft and does not send a message.
  • Villa: choose Explore in 3D, then enable the hand control to drag or pinch. Pause controls to scroll over the viewer.
  • Imagery: licensed stock inspiration, not photos of the fictional listings. Credits and font licenses are included.
  • Verification: read QA-REPORT.md for tests and limitations. Actual publication on your GitHub account happens only after your upload.
